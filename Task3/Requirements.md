## Требования

### Соответствие нормативам
- Согласие пользователей на обработку их ПД
- Системы партнеров должны соответствовать 152-ФЗ
- Интеграция должна соответствовать 152-ФЗ

### Защита данных
- TLS/SSL для передачи данных
- Шифрование для хранения данных
- Протокол OAuth 2.0 для аутентификации и авторизации

### Сеть
- Внедрение мониторинга сети и анализа трафика

### Взаимодействие

Необходимо создать новый сервис, который будет управлять умными домофоном и шлагбаумом с возможностью расширения функционала другими устройствами.

Взаимодействие через приложение:
1. Клиент приложения отправляет запрос в сервис (напрямую или через gateway) с идентификатором пользователя и идентификатором домофона/шлагбаума
2. Сервер приложения проверяет валидность полученных параметров (существование и права доступа)
3. Сервер приложения отправляет запрос в партнерский сервис
4. Партнерский сервис выполняет функцию "открыть" для домофона и/или шлагбаума
5. Сервер приложения записывает кто, когда и что открыл
6. Клиент получает ответ, что операция выполнена успешно

Взаимодействие через распознавание:
1. Сервер приложения, к которому "подключены" камеры, ведет потоковую (запросы с определенной периодичностью, например, раз в 4 секунды) передачу изображения в партнерский сервис 
2. При обнаружении валидного объекта партнерский сервис отвечает на сервер приложения идентификатором камеры (где установлена, какой домофон/шлагбаум) и идентификатором пользователя
3. Сервер приложения проверяет валидность полученных параметров (существование и права доступа)
4. Сервер приложения отправляет запрос в партнерский сервис
5. Партнерский сервис выполняет функцию "открыть" для домофона и/или шлагбаума
6. Сервер приложения записывает кто, когда и что открыл
